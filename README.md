# Affecta — эмоциональный дневник

Веб-приложение для отслеживания эмоционального состояния. Пользователь описывает ситуацию свободным текстом — система определяет эмоцию, адаптирует интерфейс и предлагает персональные практики из графа знаний.

## Возможности

- **NLP-анализ** текста на русском языке — модель [`Aniemore/rubert-large-emotion-russian-cedr-m7`](https://huggingface.co/Aniemore/rubert-large-emotion-russian-cedr-m7), 7 эмоций
- **Граф знаний** на Neo4j — эмоции, теги, стратегии и сферы жизни связаны между собой; рекомендации подбираются по контексту записи
- **Адаптивный UI** — цветовая тема, анимация маскота и плейсхолдер меняются под определённую эмоцию
- **Аналитика** — статистика эмоций с фильтрацией по тегам, инсайт маскота, стрик активности, тренды
- **A/B тестирование** — инфраструктура для сравнения эмоционального и нейтрального интерфейса (50/50 split по cookie, трекинг через Яндекс Метрику)

## Запуск

Требуется Docker Desktop.

```bash
git clone <repo-url>
cd Affecta
docker compose up -d --build
```

Первый запуск занимает 5–10 минут — загружается NLP-модель (~1.5 GB).

| Сервис | URL |
|---|---|
| Приложение | http://localhost |
| API docs (Swagger) | http://localhost/api-docs |
| Neo4j Browser | http://localhost:7474 |

Neo4j: `neo4j` / `affecta_neo4j`

## A/B тестирование

Трафик делится 50/50 между вариантами по cookie `ab`. Для ручного переключения в dev-режиме:

```bash
VITE_VARIANT=b npm run dev   # нейтральный UI
VITE_VARIANT=a npm run dev   # эмоциональный UI (по умолчанию)
```

## Исследовательская гипотеза

> Если интерфейс адаптируется под эмоцию пользователя — меняется цветовая тема, реагирует маскот, появляются эмпатичные тексты — то время на сайте увеличивается по сравнению с нейтральным интерфейсом.
